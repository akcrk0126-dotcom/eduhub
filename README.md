# PlayHub 에듀

PlayHub의 교육 게임만 모은 허브예요. → https://akcrk0126-dotcom.github.io/eduhub/

- **퀴즈 러시** — 문제를 맞혀야 움직이는 퀴즈 게임 (SAT 무한 모드 · 문제 세트 공유)
- **SAT 워들** — 다섯 글자 SAT 영단어 워들 (뜻 · 발음 · 단어장)
- **수학 블리츠** — 60초 암산 스피드전
- **의자 끝말잇기** — 표준국어대사전으로 하는 끝말잇기 (AI 1:1 · 온라인 · 사전)
- **피아노** — 88건반 웹 피아노와 클래식 자동 연주

계정 · 아바타 · 닉네임 · 레벨 · 친구는 [PlayHub](https://akcrk0126-dotcom.github.io/piblox/hub.html)와 같이 써요
